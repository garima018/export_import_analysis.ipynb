# Export-Import Analysis

## About the Project

This project analyzes India's export and import data using Python and Pandas.

## Dataset

The dataset contains information about:
- HS Code
- Commodity
- Trade Value
- Country
- Year

## Analysis Performed

- Export and Import comparison
- Top export commodities
- Top import commodities
- Export value distribution
- Top export countries
- Year-wise export and import trends
- Country-wise trade analysis
- Trade balance analysis
- Export-Import correlation

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Conclusion

The project provides insights into India's international trade patterns, major commodities, trading countries, and export-import trends.
